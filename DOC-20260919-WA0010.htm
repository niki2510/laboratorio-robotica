Problemas reales de uso

1. Sliders tactiles inestables

La version anterior reconstruia casi toda la interfaz en cada movimiento. En movil, cuando el dedo arrastra, el slider puede perder foco porque el nodo se elimina y se vuelve a crear.

2. Variables poco visibles

Habia formulas, pero faltaba una lectura clara de cada variable: valor, significado fisico, impacto sobre la curva, derivada, area e interpretacion robotica.

3. Falta puente con robotica

Para entender movimiento robotico no basta ver una curva. Hay que conectar posicion, velocidad, aceleracion, curvatura, puntos de ruta, seguimiento y error.

4. Faltan integrales

La integral explica area acumulada, distancia desde velocidad, energia aproximada, error acumulado y coste de trayectoria. Es esencial para movimiento.

Integrales, velocidad y aceleracion

Conocimiento separado del apartado de funciones

Integral definida

Suma pequenos rectangulos. En robotica puede representar distancia acumulada si f(t) es velocidad.

Derivada

Si x(t) es posicion, x'(t) es velocidad y x''(t) es aceleracion.

Error acumulado

Integrar |error(t)| permite medir cuanto tiempo y cuanto se desvia un robot de una ruta.

Coste de trayectoria

Una ruta puede evaluarse por longitud, suavidad, energia aproximada, aceleraciones bruscas y distancia a obstaculos.

Ruta robotica dibujable

Mapa libre + simulacion

Dibuja una ruta con el dedo o raton. El robot no debe saltar puntos: el simulador calcula longitud por segmentos y recorre la ruta por interpolacion acumulada.
Principio practicoUna ruta robotica es una secuencia de puntos. Para no saltar puntos se recorre la distancia acumulada segmento a segmento.
Control de seguimientoEl robot mira un punto adelantado en la ruta. Si el lookahead es pequeno, corrige mas fuerte; si es grande, suaviza pero puede recortar curvas.
CurvaturaCurvas cerradas requieren menor velocidad. Velocidad alta + radio pequeno produce errores y oscilaciones.
